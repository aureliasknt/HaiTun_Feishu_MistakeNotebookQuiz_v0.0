Entry page for the **agent basics** curriculum used by the Scenario 1 outreach
campaign. One page = one concept = the material for one daily message.

An agent is a program that uses a language model to **choose its own actions**
toward a goal, rather than only replying with text. What separates it from a
chatbot: an agent has tools, can observe the results of its actions, and then
decides what to do next.

## Learning order

1. [[What Is an Agent]] — definition, and agent vs chatbot vs workflow.
2. [[Agent Loop]] — the observe-think-act cycle that drives every agent.
3. [[Tools and Tool Calling]] — how an agent touches the outside world.
4. [[Agent Memory]] — context, short-term and long-term memory.
5. [[Agent Limits and Risks]] — hallucination, cost, irreversible actions.

## How outreach uses this

Each daily message takes one node from the order above: summarize the core of the
page, then add one opening question. The user's reply decides the next node — quick
grasp → move on; confusion → change the angle, don't repeat the same sentences.
